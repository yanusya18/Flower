# Квіткова майстерня "L’Heure Bleue"

Проєкт створено в межах навчального курсу з вебтехнологій. Це сучасний вебсайт квіткової майстерні з каталогом букетів та формою замовлення.

## Основні можливості
- Огляд популярних композицій та свіжих квітів.
- Зручна навігація за розділами.
- Форма для швидкого замовлення та зворотного зв'язку.
