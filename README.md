# Квіткова майстерня "L’Heure Bleue"

Проєкт створено в межах навчального курсу з вебтехнологій. Це сучасний вебсайт квіткової майстерні.

## Основні можливості
- Огляд квітів та продукції.
- Зручна навігація за розділами.
- Форма для швидкого замовлення та зворотного зв'язку.

## Порівняння підходів ## 

У Tailwind зручніше швидко збирати компонент і адаптивність прямо в розмітці (`md:`, `lg:`, `hover:`) без вигадування назв класів і без переходів між файлами. У звичайному CSS зручніше тримати розмітку чистою, а повторювані стилі та складну логіку (темна тема, анімації) в одному місці. Через велику кількість класів HTML у Tailwind стає довгим і важчим для читання, тому повторювані набори утиліт я виношу в компонент через `@apply` (як `.btn`).
