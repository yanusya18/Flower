## Tailwind CSS 

**Запуск.** Потрібен Node.js 20+. Встановити залежності: `npm install`. Зібрати стилі: `npm run build` (або `npm run watch` під час роботи) — результат потрапляє у `tailwind.css`, який підключено в `index.html` перед `style.css`.

**Що переписано на Tailwind.** Секція «Догляд» (картки: `grid`, `gap-5`, `shadow-md`, адаптивність `md:grid-cols-2 lg:grid-cols-4`), кнопка в hero (`px-6 py-3 rounded-lg …`) і кнопка в CTA-блоці (компонент `.btn` через `@apply`). Кольори дизайн-системи Figma додано в `@theme` у `src/input.css` і використовуються як `bg-card`, `bg-button`, `text-button-text` тощо. Preflight Tailwind не підключено, а старий `style.css` лежить у шарі `legacy`, тому решта сторінки працює як раніше.

**Порівняння підходів.** У Tailwind зручніше швидко збирати компонент і адаптивність прямо в розмітці (`md:`, `lg:`, `hover:`) без вигадування назв класів і без переходів між файлами. У звичайному CSS зручніше тримати розмітку чистою, а повторювані стилі та складну логіку (темна тема, анімації) в одному місці. Через велику кількість класів HTML у Tailwind стає довгим і важчим для читання, тому повторювані набори утиліт я виношу в компонент через `@apply` (як `.btn`).
